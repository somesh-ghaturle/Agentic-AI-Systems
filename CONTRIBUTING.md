# Contributing

Thanks for wanting to contribute to Agentic-AI-Systems. This project aims to be a practical, production-oriented reference for systematic AI enterprise architectures and runnable examples.

How to contribute

- Fork the repository and create a feature branch from `main`.
- Make small, focused commits and include a clear commit message.
- Add runnable examples under `examples/` with a README and minimal dependencies.
- Update `README.md` or add architecture notes under `/docs` as appropriate.
- Open a pull request describing the change, how to run any examples, and the rationale.

Guidelines

- Prefer reproducible examples and pinned dependencies.
- Add tests or a smoke-check where applicable for runnable examples.
- Document trade-offs and security/governance considerations for production use.

Code style

- Keep code simple and dependency-light for examples.
- Use clear, idiomatic language for the repository's primary language (Python examples: follow PEP8).

Review process

- PRs will be reviewed for clarity, reproducibility, and safety.
- Major architecture contributions may be discussed before merging.

Contact

If you need help contributing, open an issue describing what you'd like to add and a maintainer will follow up.
